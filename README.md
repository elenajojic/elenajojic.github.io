# elenajojic.github.io

My personal portfolio: projects, research, coursework, and experience from my time at the University of Michigan.

Built from scratch with HTML, CSS, and JavaScript. No frameworks or build tools. Hosted on GitHub Pages.

## Structure

```
index.html      page layout
style.css       styling
app.js          rendering and interactions (folders, halftone portrait, filters)
content.js      all site text: projects, experience, courses, links
assets/         portrait and fonts
```

## Updating content

All text lives in `content.js`. Edit the values, commit, and the live site updates within a minute or two.
